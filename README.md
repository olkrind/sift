# Sift

Веб-приложение для оценки продуктов по штрихкоду: https://olkrind.github.io/sift/

Страница статическая, запросы к базам выполняются из браузера. Камера работает только по HTTPS или на `localhost`.

## Команды

```sh
npm install
npm run dev      # сервер разработки
npm run build    # проверка типов и сборка в dist
npm run lint
```

Публикация на GitHub Pages выполняется при пуше в `main` (`.github/workflows/deploy.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Источники

Каждый источник — файл в `src/sources/`, список и приоритет заданы в `src/sources/index.ts`.

| Источник | Что даёт | Условия |
|---|---|---|
| Open Food Facts | Состав, питательность, Nutri-Score, NOVA, добавки, аллергены | Лицензия ODbL, 15 запросов в минуту на пользователя |
| USDA FoodData Central | Состав и питательность продуктов США | Запрашивается только для кодов США и Канады, `DEMO_KEY` ограничен по IP |
| Wikidata | Название | Состава нет |

Источник подходит для этого приложения, только если он отвечает браузеру с разрешающим заголовком CORS и не требует секретного ключа: ключ на статической странице доступен всем. UPCitemdb, EAN-Search, Go-UPC и Barcode Lookup этим условиям не соответствуют, для них нужен серверный посредник.

## Оценка

Формула задана в `src/score.ts`. База — Nutri-Score (A 90, B 75, C 55, D 35, E 15). Вычитается за NOVA 3 и 4 и за каждую добавку, прибавляется за органическую маркировку. Формула черновая и не прошла проверку специалистом.

Если в базе нет Nutri-Score, но есть калорийность, сахара, насыщенные жиры, соль и белки, буква рассчитывается по формулам 2023 года (`src/nutriScore.ts`) и подписывается как приблизительная. Доля фруктов и овощей при этом считается нулевой, кроме соков. Без этих данных оценка не считается. Исключения — насыщенные жиры и сахара: если их нет, буква считается для 0 и для верхней границы (весь жир, все углеводы) и показывается, когда оба расчёта совпали.

Формула выбирается по типу продукта (`src/productType.ts`), тип определяется по словам в названии и объёму упаковки:

| Тип | Правило |
|---|---|
| Алкоголь, жевательная резинка, специи, подсластители, сухие смеси и растворимые напитки | Оценка не считается |
| Вода | A, если в данных указано 0 ккал и нет сахара |
| Соки | Формула напитков с максимальным баллом за фрукты: сок считается стопроцентным |
| Напитки | Свои пороги энергии, сахара и белка; упаковка в мл или л считается напитком, если не больше 120 ккал на 100 г |
| Сыры | Общая формула, белок учитывается всегда |
| Жиры, масла, орехи | Энергия из насыщенных жиров и их доля в общем жире; от 80 г жира на 100 г определяется без слова в названии |
| Обычные продукты | Общая формула |

## Покрытие

Блок «Покрытие» считает долю продуктов с полными данными: есть состав и Nutri-Score либо калорийность. Сбои источников в процент не входят. Данные находятся в `sessionStorage` и удаляются вместе с вкладкой.
