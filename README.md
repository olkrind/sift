# Sift

Веб-приложение для оценки продуктов по штрихкоду: https://olkrind.github.io/sift/

Страница статическая, запросы к базам выполняются из браузера. Камера работает только по HTTPS или на `localhost`.

## Команды

```sh
npm install
npm run dev      # сервер разработки
npm run build    # проверка типов и сборка в dist
npm run lint
```

Публикация на GitHub Pages выполняется при пуше в `master` (`.github/workflows/deploy.yml`). В настройках репозитория: Settings → Pages → Source: GitHub Actions.

## Источники

Каждый источник — файл в `src/sources/`, список и приоритет заданы в `src/sources/index.ts`.

| Источник | Что даёт | Условия |
|---|---|---|
| Open Food Facts | Состав, питательность, Nutri-Score, NOVA, добавки, аллергены | Лицензия ODbL, 15 запросов в минуту на пользователя |
| USDA FoodData Central | Состав и питательность продуктов США | Запрашивается только для кодов США и Канады, `DEMO_KEY` ограничен по IP |
| Wikidata | Название | Состава нет |

Источник подходит для этого приложения, только если он отвечает браузеру с разрешающим заголовком CORS и не требует секретного ключа: ключ на статической странице доступен всем. UPCitemdb, EAN-Search, Go-UPC и Barcode Lookup этим условиям не соответствуют, для них нужен серверный посредник.

## Оценка

Формула задана в `src/score.ts`. База — Nutri-Score (A 90, B 75, C 55, D 35, E 15). Вычитается за NOVA 3 и 4 и за каждую добавку, прибавляется за органическую маркировку. Без Nutri-Score оценка не считается. Формула черновая и не прошла проверку специалистом.

## Покрытие

Блок «Покрытие» считает долю продуктов с полными данными: есть состав и Nutri-Score либо калорийность. Сбои источников в процент не входят. Данные находятся в `sessionStorage` и удаляются вместе с вкладкой.
